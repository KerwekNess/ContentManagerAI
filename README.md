> Интеллектуальный ассистент для управления и генерации контента.

## 📖 О проекте

ContentManagerAI — это веб-приложение на базе искусственного интеллекта, предназначенное для автоматизации создания, редактирования и управления текстовым контентом. Проект демонстрирует интеграцию AI-сервисов в простой и интуитивно понятный веб-интерфейс.

## ✨ Ключевые особенности

- Генерация текста по заданной теме с помощью AI.
- Управление историей созданных документов.
- Простой и чистый веб-интерфейс.
- Лёгкая расширяемость за счёт модульной архитектуры.

## 🛠️ Технологический стек

- **Backend:** Python, Flask
- **Frontend:** HTML, CSS, JavaScript
- **AI:** Интеграция с внешним AI API
- **Database:** SQLite (для истории)

## 🚀 Быстрый старт

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/KerwekNess/ContentManagerAI.git
   cd ContentManagerAI
   ```
2. **Установите зависимости:**
   ```bash
   pip install -r requirements.txt
   ```
3. **Настройте переменные окружения:**
   - Создайте файл `.env` в корневой папке.
   - Добавьте в него необходимые ключи (см. `.env.example`).
4. **Запустите приложение:**
   ```bash
   python app.py
   ```
